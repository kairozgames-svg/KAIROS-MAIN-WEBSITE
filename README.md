# KAIROS Main Website

Institutional website for the KAIROS digital technology ecosystem.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Cloudflare Pages compatible (static deployment)

## Local preview
Open `index.html directly in a browser, or run a local static server from the repository root.

## Project structure
- `index.html`: institutional homepage
- `assets/css/styles.css`: responsive visual system
- `assets/js/main.js`: mobile navigation and footer year
- `assets/favicon.svg`: KAIROS favicon

## Deployment
Connect this GitHub repository to Cloudflare Pages. Use the repository root as the build directory and leave the build command empty because this is a static site.

## Notes
The site links to the existing KAIROS legal/documentation portal for the SEO Intelligence product, privacy policy and terms.
